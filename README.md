# 태양과 지구와 달 · 웹 버전

기존 Pygame 프로그램을 바탕으로 별도 제작한 브라우저용 천문 시뮬레이터입니다. 원본 `17_태양과_지구와_달.py`를 수정하거나 덮어쓰지 않습니다.

## 실행

폴더 전체를 내려받고 **`index.html`**을 브라우저에서 열면 실행됩니다. 설치, API 키, Python 서버가 필요 없습니다. GitHub Pages에서도 같은 파일을 그대로 사용할 수 있습니다.

개발용 HTTP 서버가 필요하면 이 폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000`을 여세요.

## 화면과 조작

- **태양과 지구와 달**: 하루의 움직임과 공전 궤도를 함께 표시합니다.
- **태양과 달의 하루**: 중앙 애니메이션, 왼쪽 태양 정보 4개, 오른쪽 달 정보 4개를 표시합니다.
- **지구와 달의 공전**: 왼쪽 지구·태양 정보 4개, 오른쪽 달 정보 4개를 표시합니다.
- 시간 이동, 실시간 복귀, 일시정지·재생, 1~86,400배속을 지원합니다.
- `←` / `→`: 1시간 이동, `Space`: 재생·정지, `Home`: 현재 시각, `1` / `2` / `3`: 화면 선택.
- 관측 위도·경도를 입력하거나 **내 위치**를 사용할 수 있습니다. 현재 위치 조회는 HTTPS와 브라우저 위치 권한이 필요할 수 있습니다.
- 기본 좌표는 기존 프로그램의 부산 명지 기준(35.08, 128.89)입니다. 좌표는 브라우저에만 저장되며 서버에 전송하지 않습니다.

모든 표시 시각과 일출·일몰·월출·월몰의 날짜 기준은 **한국 표준시(KST, UTC+9)**입니다. 해당 날짜에 뜨거나 지지 않으면 ‘오늘 없음’으로 표시합니다. 지원 조작 범위는 1900~2050년입니다.

## 부드러운 애니메이션

`requestAnimationFrame`으로 화면 주사율에 맞춰 그립니다. 천문 계산과 날짜별 출몰 시각 탐색은 Web Worker에서 실행합니다. 약 100ms마다 다음 위치를 함께 계산하고, 화면에서는 각도의 0/360도 경계를 고려해 보간합니다. 일출·월출 등의 탐색 결과는 날짜·위치별로 캐시합니다. 실제 프레임 속도는 기기와 브라우저에 따라 달라집니다.

## 천문 계산과 그림의 의미

[Astronomy Engine](https://github.com/cosinekitty/astronomy)의 브라우저용 JavaScript를 프로젝트에 포함했습니다. 외부 CDN 없이 실행됩니다. 기존 Skyfield/DE421의 직접 실행 버전이 아니므로 계산 모델·좌표계·굴절 처리에 따른 수치 차이가 있습니다.

방향각·고도각은 관측자 기준의 날짜 적도좌표와 표준 대기 굴절 보정을 사용합니다. 공전 정보의 황경·황위는 날짜 기준 황도좌표이며, 적위는 J2000 기준입니다. 거리 단위는 태양–지구 AU, 지구–달 km입니다. 하루 경로선은 현재 적위를 고정한 일주운동 모식도이므로 달의 실제 하루 경로와 조금 다릅니다. 점선과 윤곽선 천체는 지평선 아래를 뜻합니다. 달의 밝은 면 비율은 계산한 위상을 반영하며 자세·표면 무늬는 설명용입니다. 공전 그림의 타원·천체 크기·달 궤도 배율은 관찰을 위한 모식도이고, 천체 위치 각도는 계산 결과를 사용합니다.

## GitHub Pages 배포

1. 저장소에 이 폴더의 **내용물**을 업로드합니다. 저장소 최상위에 `index.html`이 있어야 합니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
3. 브랜치 **main**, 폴더 **/(root)**를 선택하고 저장합니다.
4. GitHub가 제공하는 Pages 주소로 접속합니다.

사용자명과 저장소 이름은 프로젝트 코드에 하드코딩하지 않았습니다. 하위 경로에 배포해도 상대 경로로 작동합니다.

## 파일 구성과 수정

| 파일 | 역할 |
| --- | --- |
| `index.html` | 웹 시작 화면 |
| `solar-system-web.css` | 화면 배치와 반응형 스타일 |
| `solar-system-web.js` | 조작, 애니메이션, 화면 표시 |
| `astronomy-worker.js` | 천문 계산 소스 |
| `vendor/astronomy.browser.min.js` | 포함된 Astronomy Engine |
| `solar-system-worker.bundle.js` | 파일 직접 실행을 지원하는 계산 번들 |
| `build-web.cjs` | 계산 번들 재생성 스크립트 |

계산 코드나 라이브러리를 바꿨다면 Node.js에서 `node build-web.cjs`를 실행해 번들을 갱신합니다. 일반 실행에는 Node.js가 필요 없습니다.

기능 검사는 `node tests/check.cjs`로 실행합니다. 천문 계산의 날짜 범위·극지방·거리·한국 날짜별 출몰 시각과 화면 조작·배속·키 입력·계산 번들을 검사합니다. 실제 브라우저의 화면 배치와 프레임 속도는 별도 확인이 필요합니다.

Astronomy Engine의 MIT 라이선스는 `vendor/LICENSE.astronomy-engine.txt`에 보존했습니다. 프로젝트 자체의 배포 라이선스는 소유자가 정할 수 있도록 별도로 지정하지 않았습니다.
